# Using Xero Emoji

Live demos: [gallery](https://maximusmaximus.github.io/xeroemoji/demos/) · [chat](https://maximusmaximus.github.io/xeroemoji/demos/chat.html) · [skin tones](https://maximusmaximus.github.io/xeroemoji/demos/skin-tones.html)

## 1. File names
Every emoji has `svg/<name>.svg` (vector, viewBox 0 0 512 512) and `png/<name>.png` (512×512 RGBA, transparent).
`<name>` is the emoji's codepoints in lowercase hex, at least 4 digits, joined by `-`:

| emoji | codepoints | file |
|---|---|---|
| 😀 | U+1F600 | `svg/1f600.svg` |
| 👍🏿 | U+1F44D U+1F3FF | `svg/1f44d-1f3ff.svg` |
| 👩🏽‍🚀 | U+1F469 U+1F3FD U+200D U+1F680 | `svg/1f469-1f3fd-200d-1f680.svg` |
| ❤️ | U+2764 U+FE0F | `svg/2764.svg` (FE0F dropped) |
| #️⃣ | U+0023 U+FE0F U+20E3 | `svg/0023-20e3.svg` |
| 🇯🇵 | U+1F1EF U+1F1F5 | `svg/1f1ef-1f1f5.svg` |
| 🏳️‍🌈 | U+1F3F3 U+FE0F U+200D U+1F308 | `svg/1f3f3-200d-1f308.svg` (FE0F dropped) |

The variation selector U+FE0F is dropped from every file name, with no exceptions.

**Black line set:** the same names under `blackline/svg/`, `blackline/png/` (512) and `blackline/png-72/`. See the
README section "Black line set".

## 2. The emoji → file map
[`demos/emoji-map.json`](../demos/emoji-map.json) lists all 3,963 emoji (about 440 KB; generated by `python3 tools/build_emoji_map.py` from `qc/coverage.csv`):
```json
{ "1f44d-1f3ff": ["1f44d-1f3ff", "👍🏿", "thumbs up: dark skin tone", "People & Body", "hand-fingers-closed", 339], ... }
```
- **key**: codepoints without FE0F, so text with or without variation selectors finds the same entry;
- **value**: `[file, emoji, name, group, subgroup, order]`, where `order` is the emoji-test 18.0 position.

Python:
```python
import json
M = json.load(open('demos/emoji-map.json', encoding='utf-8'))
def xero_file(emoji, fmt='svg'):
    key = '-'.join(f'{ord(c):04x}' for c in emoji if c != '\ufe0f')
    e = M.get(key)
    return f'{fmt}/{e[0]}.{fmt}' if e else None
print(xero_file('👩🏽‍🚀'))   # svg/1f469-1f3fd-200d-1f680.svg
```

## 3. Plain HTML
```html
<img src="svg/1f680.svg" alt="🚀" width="32" height="32">
<img src="png/1f680.png" alt="🚀" width="64" height="64">
```
Put the real emoji in `alt` so copy and paste and screen readers still get it. For inline emoji in text:
```css
img.xero-emoji { width: 1.35em; height: 1.35em; vertical-align: -0.3em; }
```
The SVGs stay sharp at any size and are tuned to read at 24 and 32 px. Use the PNGs where SVG is not accepted (some chat apps, email).

## 4. The JS replacer: swap Unicode emoji in text for Xero images
[`demos/xero-emoji.js`](../demos/xero-emoji.js) is about 5 KB with no dependencies. It finds emoji with `Intl.Segmenter`, falling back to longest-match against the map, and handles ZWJ sequences, skin tones, flags, keycaps and tag sequences.
```html
<script src="https://maximusmaximus.github.io/xeroemoji/demos/xero-emoji.js"></script>
<script>
  XeroEmoji.load({ base: 'https://maximusmaximus.github.io/xeroemoji/' })   // or './' when self-hosting a copy of this repo
    .then(X => {
      X.parse(document.body);                           // replace emoji in every text node (skips script/style/inputs)
      el.innerHTML = X.toHTML('Ship it 🚀👍🏽');          // escapes the text, then adds <img class="xero-emoji" ...>
      console.log(X.find('🇯🇵'));                       // {file:'1f1ef-1f1f5', name:'flag: Japan', src:'.../svg/1f1ef-1f1f5.svg', ...}
    });
</script>
```
Options for `load()`:
- `base`: the URL of the repo root, where `svg/`, `png/` and `demos/` live;
- `format`: `'svg'` (default) or `'png'`;
- `className`: default `xero-emoji`;
- `textStyle: true`: also replaces bare text-style characters such as © or ™ that have no U+FE0F.

The images keep the original emoji as `alt` and the CLDR name as `title`.

## 5. Skin tones
Skin-tone variants insert U+1F3FB…U+1F3FF after the person or hand, before any ZWJ: `1f44b` → `1f44b-1f3fd`; `1f9d1-200d-1f373` → `1f9d1-1f3fd-200d-1f373`.
Multi-person emoji take one modifier per person, e.g. `1f9d1-1f3fb-200d-1f91d-200d-1f9d1-1f3ff`. See [the skin-tone demo](https://maximusmaximus.github.io/xeroemoji/demos/skin-tones.html).

## 6. Running the QC yourself
```bash
pip install numpy pillow cairosvg scikit-image imagehash
cd qc && python3 -m xeroqc run          # full set -> qc/results/<timestamp>PT/
python3 -m unittest discover -s tests   # scorer tests
bash verify_locks.sh                    # md5 of every approved file
```
