Emoji picker widget

xero-emoji-picker.js is a small, dependency-free picker with search, category tabs and a skin-tone switch. It ships in the xeroemoji npm package.

Inline picker

Use it

<script src="https://cdn.jsdelivr.net/gh/maximusmaximus/xeroemoji@main/packages/npm/xero-emoji-picker.js"></script>
<script>
  XeroEmojiPicker.attach(document.querySelector('#btn'), {
    onSelect: e => input.value += e.emoji   // e = { emoji, name, file, url }
  });
</script>
