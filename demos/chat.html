Chat demo

Messages are plain Unicode text. xero-emoji.js swaps every emoji for a Xero Emoji image when it is shown, so copy and paste still give you real emoji. Type your own below.

Tip: the emoji keyboard is Win + . on Windows, Ctrl + Cmd + Space on macOS.

How this page does it 
<script src="xero-emoji.js"></script>
<script>
  XeroEmoji.load({ base: '../' }).then(X => {
    bubble.innerHTML = X.toHTML(messageText);   // escapes the text, then inserts <img class="xero-emoji">
  });
</script>
